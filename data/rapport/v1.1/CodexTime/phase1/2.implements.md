# Etape 2 - Prompt d'implémentation

Contexte:
- Le lot précédent a introduit le runtime minimal: `WorkflowRun`, `LotRun`, `WorkflowExecutionContext` et statuts.
- Cette étape doit introduire uniquement le contrat minimal des étapes de workflow.

Objectif:
Implémenter, dans `fr.ses10doigts.toolkitbridge.service.agent.workflow.runtime.step`:
1. `WorkflowStep`
2. `WorkflowStepDecision`
3. `WorkflowStepResult`

Contraintes strictes:
- Pas de moteur de workflow
- Pas d'orchestrator
- Pas de gestion de séquence, pipeline, transitions, retry
- Pas de dépendances Telegram/Codex/Maven
- API minimale uniquement

Contrat attendu:
- `WorkflowStep`: méthode unique `execute(WorkflowExecutionContext) -> WorkflowStepResult`
- `WorkflowStepDecision`: `CONTINUE`, `RETRY_CORRECTION`, `WAIT_HUMAN`, `STOP_FAILURE`, `FINISH`
- `WorkflowStepResult`: `decision` obligatoire, `message` optionnel, `data` optionnelle (`Map<String,Object>` défensive)

Tests minimaux:
- Construction nominale `WorkflowStepResult`
- `decision` obligatoire
- immutabilité défensive de `data`
- test dummy simple d'une implémentation `WorkflowStep`
