# Etape 3 - Prompt d'implémentation

Objectif:
Implémenter une brique technique locale d'exécution Codex CLI, sans logique métier workflow.

A implémenter dans `fr.ses10doigts.toolkitbridge.service.agent.workflow.runtime.codex`:
1. `CodexExecutionRequest`
2. `CodexExecutionResult`
3. `CodexWorkflowClient`
4. `CodexExecutionException` (technique, minimale)

Contraintes:
- `prompt` obligatoire
- `workingDirectory` en `Path`, optionnel
- `timeoutSeconds` optionnel, strictement positif si renseigné
- pas d'orchestrator, pas de retry, pas de décision métier
- `CodexExecutionResult` neutre: command/exitCode/stdout/stderr/success/timedOut/durationMs

Technique:
- `ProcessBuilder`
- capture stdout/stderr
- `waitFor(timeout, TimeUnit.SECONDS)`
- destruction propre en cas de timeout
- mesure simple de durée

Tests minimaux:
- `CodexExecutionRequestTest`
- `CodexExecutionResultTest`
- `CodexWorkflowClientTest` sobre (validation d'entrée)
