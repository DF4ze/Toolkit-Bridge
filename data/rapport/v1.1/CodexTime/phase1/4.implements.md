Objectif:
Implémenter une brique documentaire technique de gestion d'artefacts workflow, sans logique métier ni orchestration.

A implémenter:
1. `WorkflowArtifactType` (enum de nommage)
2. `WorkflowArtifactService` (build path / write / read / exists)

Package cible:
- `fr.ses10doigts.toolkitbridge.service.agent.workflow.runtime.artifact`

Contraintes:
- API sobre et lisible
- usage de `Path`
- création défensive des répertoires à l'écriture
- pas de parsing sémantique
- pas de couplage à Codex/Telegram/Maven/WorkflowStep

Tests minimaux:
- nommage de fichier par type+étape
- construction de chemin
- écriture puis lecture
- existence de fichier
