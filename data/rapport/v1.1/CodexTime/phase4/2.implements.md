Objectif

Rendre l’exécution de `CorrectionStep` conditionnelle après `GlobalReviewStep`.

À modifier

- `WorkflowOrchestrator`
- `GlobalReviewStep`
- `WorkflowOrchestratorTest`
- `GlobalReviewStepTest`

1. Convention Review

Dans `GlobalReviewStep` :

Détecter dans stdout :

- `DECISION: NEED_CORRECTION`
- `DECISION: OK`
- `DECISION: WAIT_HUMAN` (déjà existant)

2. Exposition du flag

Dans `WorkflowStepResult.data` :

Ajouter :

```java
requiresCorrection = true / false
```

obligatoire uniquement si decision = CONTINUE

3. Nouvelle méthode orchestrator

Ajouter :

```java
executeAnalysisReviewWithOptionalCorrection(
    WorkflowExecutionContext context,
    WorkflowStep analysisStep,
    WorkflowStep reviewStep,
    WorkflowStep correctionStep
)
```

4. Comportement

1. exécuter analysis
   -> si != CONTINUE -> return

2. exécuter review
   -> si WAIT_HUMAN -> return
   -> si STOP_FAILURE -> return

3. si CONTINUE :
   - si requiresCorrection == true -> exécuter correction -> return résultat
   - sinon -> return CONTINUE avec message explicite
     "Review completed - no correction required"

5. Règles importantes

- ne pas parser les artefacts dans l’orchestrator
- ne pas modifier `CorrectionStep`
- ne pas introduire de moteur
- ne pas créer de nouvelle classe
- ne pas modifier `WorkflowExecutionContext`

6. Tests

GlobalReviewStepTest
- NEED_CORRECTION -> flag true
- OK -> flag false

WorkflowOrchestratorTest
- NEED_CORRECTION -> correction exécutée
- OK -> correction non exécutée
- WAIT_HUMAN -> arrêt immédiat
- STOP_FAILURE -> arrêt immédiat
