---

## 4. Adaptation du CLI

Le CLI doit exposer :

* decision
* message (jamais null → fallback "")
* finalDecision
* nextAction
* correctionTriggered
* waitReason (si présent)
* workflowSummaryPath (si présent)

* une ligne par champ
* format `key=value`
* aucune valeur null
