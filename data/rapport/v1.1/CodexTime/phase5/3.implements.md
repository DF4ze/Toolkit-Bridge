## Objectif

Implémenter un consommateur externe simulé minimal pour valider l’exploitabilité du contrat CLI.

---

## 1. Classe à créer

Créer une classe :

WorkflowCliConsumerSimulator

---

## 2. Responsabilités

* recevoir une sortie CLI brute (`String`)
* parser `key=value` → `Map<String, String>`
* interpréter le résultat
* produire un statut simple

---

## 3. Parsing

Règles :

* lire ligne par ligne
* ignorer lignes vides
* split sur le premier `=`
* trim clé
* conserver valeur (trim léger)

Tolérance :

* ligne invalide → ignorée
* clé inconnue → ignorée
* clé absente → fallback

---

## 4. Interprétation

Basée sur :

* `finalDecision` (prioritaire)
* fallback sur `decision`

Mapping recommandé :

* WAIT_HUMAN → WAITING_FOR_HUMAN
* STOP_FAILURE → FAILED
* CONTINUE → SUCCESS
* autre → UNKNOWN

Si exit code non-zero → ERROR

---

## 5. Exploitation

* afficher `message`
* afficher `nextAction`
* afficher `waitReason` si présent
* afficher `workflowSummaryPath` si présent

⚠️ ne pas parser `nextAction`
⚠️ ne pas parser le summary

---

## 6. Gestion WAIT_HUMAN

* afficher instructions
* ne pas relancer automatiquement
* attendre intervention humaine
* permettre appel manuel de RESUME

---

## 7. Tests

Créer tests unitaires :

* parsing nominal
* champs manquants
* lignes invalides
* WAIT_HUMAN
* STOP_FAILURE
* SUCCESS
* UNKNOWN
* sortie CLI invalide

⚠️ ne pas lancer de process réel
