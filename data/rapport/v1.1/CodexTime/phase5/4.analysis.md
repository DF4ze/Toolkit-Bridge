---

## 2. Objectif réel de l’étape

Je veux maintenant vérifier si le système peut supporter un flow utilisateur complet du type :

1. un utilisateur déclenche le workflow
2. le système répond avec un message exploitable
3. si `WAIT_HUMAN`, l’utilisateur intervient
4. l’utilisateur déclenche une reprise
5. le système répond avec un nouveau message exploitable

Le but est de simuler une interaction proche Telegram, mais sans Telegram.

---

## 3. Ce que cette étape doit simuler

Une interaction utilisateur minimale :

* commande utilisateur : `run`
* réponse système
* commande utilisateur : `resume`
* réponse système

Exemple conceptuel :

```text
User: run phase5 step4
System: WAIT_HUMAN — edit review result then resume

User: resume phase5 step4
System: CONTINUE — correction completed
```
