## Objectif

Simuler une interaction utilisateur complète autour du workflow :

RUN → WAIT_HUMAN → RESUME

Sans introduire de moteur de conversation.

---

## 1. Classe à créer

Créer :

WorkflowUserInteractionSimulator

---

## 2. Responsabilités

* recevoir une sortie CLI brute
* utiliser `WorkflowCliConsumerSimulator`
* produire un message utilisateur lisible
* ne pas stocker d’état
* ne pas automatiser les transitions

---

## 3. Méthode principale

Créer une méthode :

renderMessage(SimulatedConsumerResult result)

Qui produit un texte du type :

Status: WAITING_FOR_HUMAN
Message: ...
Reason: ... (si présent)
Next action: ...
Summary: ... (si présent)

---

## 4. Simulation RUN

Dans un test :

* fournir une sortie CLI RUN
* parser via `WorkflowCliConsumerSimulator`
* générer message

---

## 5. Simulation WAIT_HUMAN

* vérifier que le message contient :

  * message
  * waitReason
  * nextAction
  * summary path
* ne pas déclencher de resume automatiquement

---

## 6. Simulation RESUME

* fournir une sortie CLI RESUME
* parser
* générer message SUCCESS

---

## 7. Gestion des erreurs

Tester :

* ERROR
* FAILED
* UNKNOWN

Avec messages lisibles.

---

## 8. Contraintes

* pas de bot
* pas de state machine
* pas de stockage d’état
* pas de parsing du summary
* pas de parsing de nextAction

---

## 9. Tests

Créer tests :

* run → WAIT_HUMAN
* WAIT_HUMAN → pas de resume auto
* resume → SUCCESS
* STOP_FAILURE
* ERROR
* UNKNOWN
