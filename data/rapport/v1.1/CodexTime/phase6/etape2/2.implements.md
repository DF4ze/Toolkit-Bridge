# PROMPT — Implémentation Phase 6 Étape 2 — MavenValidationStep

## Contexte

La validation locale (`WorkflowValidationService`) est implémentée et testée.

Objectif :

👉 Ajouter une validation Maven réelle dans le workflow
👉 Sans casser l'architecture existante

---

## Travail demandé

---

## 1. Créer `MavenValidationStep`

Créer :

`MavenValidationStep.java`

Implémente :

```java
WorkflowStep
```

---

### Responsabilités

* construire une `ValidationCommand`
* appeler `WorkflowValidationService`
* mapper vers `WorkflowStepResult`

---

### Commande Maven

Windows :

```
cmd.exe /c mvnw.cmd clean compile -DskipTests
```

Linux/Mac :

```
./mvnw clean compile -DskipTests
```

---

### Working directory

* doit pointer vers la racine du projet
* récupérer depuis le contexte (existant ou à définir)

---

### Timeout

* 180 à 300 secondes

---

### Mapping résultat

| ValidationStatus | WorkflowStepDecision |
| ---------------- | -------------------- |
| SUCCESS          | CONTINUE             |
| FAILURE          | STOP_FAILURE         |
| TIMEOUT          | STOP_FAILURE         |
| SYSTEM_ERROR     | STOP_FAILURE         |

---

### Data à enrichir

Ajouter dans `WorkflowStepResult.data` :

* `buildStatus`
* `buildExitCode`
* `buildDurationMs`
* `buildResultPath`

---

### Artifact

Utiliser `WorkflowArtifactService` pour :

* écrire stdout/stderr Maven dans un fichier
* retourner le chemin (`buildResultPath`)
