# PROMPT - Analyse Phase 6 Etape 4 - STOP_FAILURE vs WAIT_HUMAN

## Contexte

Le systeme actuel :

* corrige automatiquement les erreurs de build
* s'arrete en `STOP_FAILURE` si :

  * max retry atteint
  * erreur non corrigeable
  * probleme systeme

---

## Probleme

Tous les `STOP_FAILURE` sont traites pareil.

Or certains cas devraient etre :

```text
WAIT_HUMAN
```

---

## Objectif

Analyser comment introduire une distinction claire entre :

* echec technique -> STOP_FAILURE
* incertitude / decision -> WAIT_HUMAN

---
