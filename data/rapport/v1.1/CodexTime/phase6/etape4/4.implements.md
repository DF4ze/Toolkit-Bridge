# PROMPT - Implementation Phase 6 Etape 4 - WAIT_HUMAN intelligent

## Contexte

Le systeme :

* corrige automatiquement les erreurs de build
* s'arrete en `STOP_FAILURE` en cas d'echec

Objectif :

Transformer certains `STOP_FAILURE` en `WAIT_HUMAN`.

## Travail demande

## 1. Modifier `AnalysisReviewWorkflowRunner`

Dans :

```java
runWithValidationAndRetry(context)
```

### Nouveau comportement

A la fin du cycle :

```text
si decision == STOP_FAILURE
  ET buildStatus == FAILURE
  ET correctionTriggered == true
  ET retry max atteint
-> convertir en WAIT_HUMAN
```

### Resultat attendu

```text
decision = WAIT_HUMAN
finalDecision = WAIT_HUMAN
```

## 2. Ajouter `waitReason`

Exemple :

```text
Build still fails after automatic correction attempts
```

## 3. Adapter `nextAction`

Exemple :

```text
Inspect build artifact and correction attempt, then decide how to proceed
```

## 4. Conserver STOP_FAILURE pour

* TIMEOUT
* SYSTEM_ERROR
* etat retry invalide

## 5. Adapter le summary

Dans la generation de `workflow-summary.md` :

Si `WAIT_HUMAN` + build context :

Remplacer :

```text
Edit review result...
```

par :

```text
1. Inspect build artifact
2. Inspect correction attempt
3. Fix manually or adjust strategy
4. Resume workflow
```

## 6. Tests a ajouter

* retry max atteint -> WAIT_HUMAN
* TIMEOUT -> STOP_FAILURE
* SYSTEM_ERROR -> STOP_FAILURE
* retry non declenche -> STOP_FAILURE
