# PROMPT - Analyse Phase 6 Etape 5 - Summary exploitable

## Contexte

Le systeme produit actuellement :

* un fichier `workflow-summary.md`
* une sortie CLI (`key=value`)
* des decisions (`CONTINUE`, `STOP_FAILURE`, `WAIT_HUMAN`, etc.)

Le workflow est maintenant :

* techniquement fiable
* capable d'auto-correction
* capable de s'arreter intelligemment

## Probleme

Le `workflow-summary.md` :

* est lisible
* mais reste oriente technique
* et pas encore optimise pour :

  * un humain
  * un futur bot Telegram

## Objectif

Transformer le summary en interface humaine universelle, lisible sans contexte technique, sans lire le code et sans aller chercher d'autres fichiers.

## Travail demande

### 1. Evaluer le summary actuel

Analyser :

* lisibilite globale
* clarte des informations
* comprehension immediate
* actionabilite

### 2. Identifier les problemes

Par exemple :

* trop verbeux ?
* pas assez structure ?
* melange info technique / action ?
* manque de hierarchie ?
* difficile a lire dans Telegram ?

### 3. Proposer une structure cible

Pour chaque cas :

* SUCCESS
* STOP_FAILURE
* WAIT_HUMAN (review)
* WAIT_HUMAN (build)

### 4. Definir un format standard

Proposer une structure claire, par exemple :

```text
Status: ...
Reason: ...

Context:
...

Actions:
1.
2.
3.
```

### 5. Verifier compatibilite Telegram

Analyser :

* taille du message
* lisibilite brute
* decoupage possible
* absence de parsing complexe

### 6. Verifier autonomie du summary

Le summary doit etre :

* autonome
* compréhensible seul
* sans dependance obligatoire a d'autres fichiers

### 7. Definir les donnees essentielles

Identifier ce qui doit toujours etre present :

* status
* reason
* nextAction
* contexte minimal
* liens utiles (paths)

### 8. Proposer des exemples concrets

Donner des exemples pour :

* SUCCESS
* STOP_FAILURE
* WAIT_HUMAN build
* WAIT_HUMAN review

### 9. Plan d'implementation

5 a 10 etapes max.

## Contraintes strictes

* ne pas implementer
* ne pas ajouter Telegram
* ne pas creer moteur template
* rester simple
* ne pas casser le contrat existant
